你的网站

我也想要有个人网站

我使用的是 GitHub Pages。目前我所知道的一共有两个选择，我给他们的优缺点都写出来了。

sxl 上线了

  • 优点很多人都在用这个，自带可视化创建网页工具，国内连接稳定
  • 缺点限制较多，比如不能直接放文件，免费版最多搞 5 个页面等
去 sxl.cn 看看

GitHub Pages

  • 优点可以直接放文件，可以搞无数个页面，仓库大小理论上没有上限
  • 缺点但超过 1GB 会有风险，没有可视化工具，国内延迟较高
去看 GitHub Pages 文档
